ISWT WPF 프로젝트 - 개편본

구성
- 첫 실행 화면: 환자 기본정보, 안정 시 SpO2/HR/BP, mMRC, 산소 흡입량, 분당 호흡수 입력
- 예측 최대 심박수: 210 - (나이 x 0.65)
- 85% 목표 심박수: 예측 최대 심박수 x 0.85
- 입력 완료 후 기존 ISWT 검사 화면으로 이동
- 입력 정보는 검사 결과 리포트로 전달
- ESWT: ISWT 기반 VO2 자동 계산 또는 담당의 단계 입력
- ESWT 보행속도는 소수점 첫째 자리 표시
- ESWT 1셔틀 카운트다운 및 총 운동 경과시간 타이머
- 검사 종료 시 총 운동시간 및 속도 기반 보행거리 기록

실행
1. ZIP을 압축 해제합니다.
2. Windows에서 Visual Studio 2026으로 ISWT.csproj를 엽니다.
3. .NET 10 SDK 및 ".NET 데스크톱 개발" 워크로드가 설치되어 있어야 합니다.
4. 빌드: Ctrl+Shift+B
5. 실행: F5

주의
- 이 작업 환경은 Windows WPF 빌드 환경이 아니므로 실제 Windows 빌드/실행 검증은 수행하지 못했습니다.
- XAML XML 구문과 XAML 이벤트 핸들러 연결은 정적 점검했습니다.
- 임상 현장에 적용하기 전 ISWT/ESWT 단계표, 셔틀 시간, 거리 산출 및 경고 기준을 담당 전문가가 검증해야 합니다.
- 환자 개인정보 및 결과 파일을 공개 저장소에 업로드하지 마세요.
